# media 目录

| 目录 | 内容 | 命名 |
| --- | --- | --- |
| `persona/<版本>/` | 人设参考图（正面/侧脸/全身/表情） | `ref-front.png`、`ref-side.png`、`ref-full.png` |
| `bgm/` | 背景音乐 | `<日期>-<风格>-<短名>.mp3` |
| `sfx/` | 音效 | `<日期>-<类型>-<短名>.mp3` |
| `covers/` | 封面、标题图 | `<日期>-<短名>-cover.png` |

- 参考图建议 PNG/WebP、≤5MB；BGM/音效 MP3 128–320kbps。
- 每个文件都要在 `licenses/` 有对应记录。
